Security, Privacy & Data Ethics

Your medical records belong strictly to you. BloodReport AI adheres to essential data protection principles:

No Public Exposure

Uploaded reports are never publicly accessible or indexed.

Strict File Validation

Uploads are restricted to legitimate PDF and image file types with size validation.

User Data Control

You have the permanent right to delete stored reports and results at any time.

Data Minimization

We only store variables directly needed for clinical interpretation.

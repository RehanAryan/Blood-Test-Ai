# BloodReport AI

An AI-powered blood test analysis platform that allows users to upload blood test reports, extract laboratory values, compare them with appropriate reference ranges, compare current results with previous reports, visualize changes through interactive Chart.js graphs, and receive simple educational explanations.

> **Important Medical Disclaimer:**  
> AI-generated information is for educational purposes only and does not replace professional medical advice.

---

## Google Gemini API Integration

The application uses Google's **Gemini 1.5 Flash** model for:
1. **Dynamic Biomarker Extraction**: Parses uploaded documents or pasted lab report text and extracts structured laboratory values, units, and reference ranges into valid JSON.
2. **Dynamic Clinical Summaries**: Synthesizes natural plain-language educational summaries detailing overall trajectory, improved values, worsened values, and values requiring clinical attention.
3. **Doctor Discussion Agenda**: Formulates 4–5 prioritized questions tailored to the patient's actual biomarker deviations.
4. **Biomarker Deep Dives**: Explains individual tests, physiological significance, and non-disease lifestyle factors affecting results on demand.

### Configuring Your Gemini API Key
The Gemini API key is maintained securely on the server and is **never** entered or stored on the website:
1. Open the `.env` file in the project root.
2. Add your Google Gemini API key:
   ```env
   GEMINI_API_KEY=your_actual_gemini_api_key_here
   ```
   Get a free API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
3. The backend securely loads this key to power AI extraction, clinical summaries, and biomarker deep-dives.

## 10 Core Pages

1. **Landing Page (`#viewLanding`)**: Medical design, hero section, features, previous vs. current comparison preview, privacy/security section, and medical disclaimer.
2. **Patient Profile (`#viewProfile`)**: Stores Name, Age, Sex, DOB, Height, Weight, and Pregnancy status (applied only where clinically relevant).
3. **Upload Report Page (`#viewUpload`)**: Drag-and-drop file upload (PDF, JPG, PNG, TXT), paste raw report text, animated OCR progress bar, and an **editable verification table** allowing users to correct OCR mistakes before running analysis.
4. **Report Analysis Page (`#viewAnalysis`)**: Displays every test in a table with Test Name, Current Result, Unit, Reference Range (laboratory-printed vs validated fallback), Status (Normal, Low, High, Critical), Previous Result, and Change.
5. **Previous vs. Current Comparison (`#viewComparison`)**: Select previous report & current report to compute absolute change, percentage change, and **context-aware clinical trend** (e.g. LDL decreasing is an improvement, Vitamin D rising is an improvement). Features interactive Chart.js trend curves.
6. **AI Summary (`#viewAISummary`)**: Dynamic, simple-language summary generated by Gemini AI detailing overall trend, improved values, worsened values, abnormal values needing attention, and prioritized questions for doctor consultation.
7. **Clinical Dashboard (`#viewDashboard`)**: 4 KPI cards for **NORMAL**, **LOW**, **HIGH**, and **NEEDS ATTENTION**, plus total tests, abnormal count, improved count, worsened count, and overall trend.
8. **Report History (`#viewHistory`)**: Stored timeline of previous reports by date with 1-click comparison.
9. **Test Detail View (`#testDetailModal`)**: Deep-dive modal for any test showing reference ranges, previous results, interactive trend line graph, simple explanation, factors affecting results, and doctor guidance.
10. **Doctor-Ready Summary (`#viewDoctorSummary`)**: Printable and PDF-exportable document dynamically populated from the active report and Gemini analysis.

### How to Run
1. Make sure your `.env` file has your `GEMINI_API_KEY`:
   ```env
   GEMINI_API_KEY=your_actual_key_here
   ```
2. Start the Python Flask backend:
   ```bash
   pip install -r backend/requirements.txt
   python backend/app.py
   ```
3. Open your browser to `http://localhost:5000` to access the full application with server-side AI processing.
4. *(Note: You can also open `index.html` directly for client preview with local rule-based parsing).*
